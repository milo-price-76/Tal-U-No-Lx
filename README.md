## 📖 About

TAL-U-NO-LX is developed by Togu Audio Line, a small Swiss audio software studio known for vintage emulation plugins. The synthesizer models the Juno 60 oscillator, filter, and chorus section with a calibrated signal path, adds a portamento and arpeggiator section, and exposes every control through a clean single panel. Recent builds include improved filter resonance behavior, a resizable interface, and MIDI learn for hands on control.

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Plugin not listed in the DAW | Rescan the VST3 folder in your DAW plugin manager. |
| No sound on a MIDI track | Arm the track and check that a MIDI input is selected. |
| Interface appears too small | Drag the bottom right corner of the plugin window to resize. |
| Installer closes without finishing | Reboot, close the DAW, then run the setup file again. |
| Crackling or audio dropouts | Raise the buffer size in your audio interface settings. |
| MIDI controller not responding | Enable the device under MIDI learn and assign a knob. |
